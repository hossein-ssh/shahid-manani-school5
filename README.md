# سامانه جامع مدیریت دبیرستان و مؤسسه آموزشی هوشمند اندیشه ساری
## Andisheh Sari Smart Educational Management System

سامانه جامع، امن و هوشمند مدیریت آموزشی و پرتال دبیرستان اندیشه ساری، پیاده‌سازی شده با پشته مدرن Full-Stack (React 19 + TypeScript + Express + Tailwind CSS).

---

### ۱. ویژگی‌ها و قابلیت‌های برجسته سیستم

1. **امنیت ورود و کنترل حساب‌ها (بدون امکان ثبت‌نام آزاد دانش‌آموز)**:
   - دانش‌آموزان به هیچ وجه امکان ثبت‌نام خودسرانه ندارند.
   - حساب‌ها و رمزهای عبور صرفاً توسط معاون آموزشی در پنل مدیریت صادر و به اولیا و دانش‌آموزان تحویل داده می‌شود.
2. **پایه‌ها و کلاس‌های دوره اول متوسطه**:
   - پوشش پایه‌های هفتم، هشتم و نهم.
   - تعداد کلاس‌ها و نام‌گذاری شعبات (مانند ۹۰۱، ۹۰۲، ۸۰۱ و ...) توسط معاون آموزشی ثبت و کنترل می‌شود.
3. **تعریف مستقل و انتصاب تخصصی معلمان به ازای هر درس در هر کلاس**:
   - دارای بخش مجزای «مدیریت معلمان» در پنل معاون.
   - امکان انتخاب دبیر برای هر درس در هر کلاس به صورت کاملاً مستقل (مثلاً در کلاس ۹۰۱ درس ریاضی با «استاد قنبری» و در کلاس ۹۰۲ همان درس ریاضی با «استاد علوی»).
   - پشتیبانی از چند دبیر همکار (مانند آزمایشگاه و دبیر مشترک).
4. **کارنامه تحلیلی دقیق و نمودار پیشرفته (مطابق تصاویر پیوست)**:
   - ثبت و محاسبه خودکار معدل کل دانش‌آموز، میانگین کلاس و میانگین کل پایه تحصیلی.
   - محاسبه رتبه کل در کلاس و رتبه کل در پایه.
   - **محاسبه و نمایش تفکیک‌شده رتبه در کلاس و رتبه در پایه برای تک‌تک دروس به صورت مجزا**.
   - نمودار مقایسه‌ای وضعیت نمرات هر درس با میانگین کلاس و میانگین پایه.
   - سیستم تحلیل عملکرد با نشانگرهای سبز و قرمز (بالاتر از میانگین / پایین‌تر از میانگین).

### ۳. نحوه راه‌اندازی و اجرای محلی در ویندوز (Windows)

برای راه‌اندازی سریع در ویندوز، فایل‌های Batch زیر تعبیه شده‌اند:
- **`install.bat`**: نصب خودکار کلیه کتابخانه‌ها با دستور `npm install`
- **`start.bat`**: راه‌اندازی سرور فول‌استک روی پورت ۳۰۰۰ با دستور `npm run dev`
- **`build.bat`**: ساخت پکیج بهینه‌شده تولیدی با دستور `npm run build`

همچنین برای مطالعه دستورالعمل‌های جزئی به فایل **`PERSIAN_SETUP_GUIDE.md`** مراجعه فرمایید.

#### راه‌اندازی دستی:
```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه یکپارچه (Front-end + Back-end روی پورت ۳۰۰۰)
npm run dev
```
سپس در مرورگر به آدرس زیر بروید:
```text
http://localhost:3000
```
